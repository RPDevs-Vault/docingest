Request Weight: **1** Action Weight: **10**

#### Body

application/json

Auto-cancel request.

[​](https://docs.polymarket.com/api-reference/set-auto-cancel#body-op)

op

object

required

Show child attributes

[​](https://docs.polymarket.com/api-reference/set-auto-cancel#body-sig)

sig

string

required

Signature in hex format

Example:

`"0x1234567890..."`

[​](https://docs.polymarket.com/api-reference/set-auto-cancel#body-salt)

salt

integer

required

Salt

Example:

`1234567890`

[​](https://docs.polymarket.com/api-reference/set-auto-cancel#body-ts)

ts

integer

required

Request timestamp. Unix milliseconds for most operations; Unix seconds for withdrawals (must match the on-chain EIP-712 struct verified against block.timestamp).

Example:

`1767225600000`

#### Response

200

application/json

The effective auto-cancel schedule after the update.

The auto-cancel schedule now in effect. The deadline field echoes the armed time in Unix milliseconds, or 0 if you cleared the schedule.

[​](https://docs.polymarket.com/api-reference/set-auto-cancel#response-status)

status

enum<string>

required

Available options:

`ok`

[​](https://docs.polymarket.com/api-reference/set-auto-cancel#response-deadline)

deadline

integer

required

Deadline of the armed auto-cancel schedule, in Unix milliseconds. Zero means no schedule is armed. When the deadline passes, the exchange cancels every open order on the account and the schedule clears.

Example:

`1767000045000`
